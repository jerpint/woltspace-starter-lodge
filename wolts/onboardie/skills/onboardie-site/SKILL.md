# Onboardie's site

The pages live in `site/` next to this file. Seeds don't carry sites, so this skill does.

Install or restore: copy every file in `.claude/skills/onboardie-site/site/` into `wolt/site/` (overwrite those
files only; keep any page you added yourself), then `push-view /wolt/onboardie/site/`.

When you update a page for good, update the copy here too, so the next lodge gets it.
